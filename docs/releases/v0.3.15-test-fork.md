## 0.3.15 TEST

- Дополнительный вариант для ABI OnePlus / Wild `android16-6.12.38`: стандартный модуль 6.12 и остальные KMI сохранены.
- Автоматический выбор между вариантами 6.12 по проверенным данным ABI; для известной сборки добавлен профиль GNU build ID и полного баннера ядра.
- В Manual inject добавлен отдельный пункт OnePlus 6.12.38. Проверки самого ядра при загрузке не отключаются.
- Manual inject: ровная сетка из двух колонок с одинаковыми отступами; показаны только варианты текущей ветки Linux (например, 5.10 или 5.15), без выбора чужой ветки.
- Добавлена поддержка кнопки «Обновить» в совместимых рут-менеджерах. Канал обновлений содержит только обычные релизы, без prerelease; версия и versionCode берутся из публикуемого ZIP.
- Добавлены регрессионные проверки выбора ABI, ручной загрузки, анализа Image и канала обновлений.

Первую установку этой версии выполните вручную: в старых ZIP ещё нет адреса обновлений. Кнопка появится при выходе следующего обычного релиза с большим versionCode.

Тестовая версия. Совместимость конкретного телефона и работа хуков требуют проверки на устройстве.
