# HMA UID Fake fork 0.3.8 TEST — диагностика одним действием

**Тестовая версия / prerelease.** Стабильным Latest остаётся 0.3.7-fork.

## Изменения

- В самом низу главного меню WebUI добавлен пункт **Save diagnostics / Сохранить диагностику** в стиле существующих строк. Геометрия остальных меню не менялась.
- После подтверждения конфиденциальности создаётся архив `Download/uidfake-diagnostics-….tar.gz`. Путь показывается с кнопкой копирования. Повторный запуск во время сбора блокируется.
- В архив входят статус ядра/хуков, выбранный KMI, повторная проверка выбора **без загрузки**, журнал загрузчика и синхронизации, конфигурация ядра, список загруженных модулей, dmesg, ограниченный Android-журнал и конфигурации правил UIDFAKE/HMA/HMA-OSS.
- Для проверки ABI сохраняются build-ID/taint загруженных модулей и до трёх доступных модулей-образцов. Объём файлов и время команд ограничены; отсутствующие данные отмечаются в manifest. Частичные файлы не выдаются за готовый архив.
- Работает и при незагруженном UIDFAKE: недоступные статусы остаются в диагностике. Настройки, хуки и способ загрузки не изменяются. Исправление пересчёта политики после установки приложений в эту сборку не включено.

## Проверка

Установите `hma-uidfake-fork-0.3.8-test.zip` поверх старой версии и перезагрузитесь. Откройте WebUI → прокрутите главное меню вниз → **Save diagnostics** → подтвердите сохранение. После сообщения об успехе отправьте архив из Download лично разработчику.

**Конфиденциальность:** архив содержит названия установленных приложений, правила скрытия, сведения о сборке и технические журналы. Не публикуйте его открыто. Автоматической отправки нет; данные приложений, пароли и полный logcat не собираются. Отдельные технические журналы могут содержать идентификаторы.

Версия `0.3.8-test-fork`, versionCode `3008`. Ядровой код, восемь KMI и логика загрузки сохранены от 0.3.7. Успешная CI-сборка не заменяет тест экспорта на телефоне.
