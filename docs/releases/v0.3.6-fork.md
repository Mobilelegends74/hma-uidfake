# HMA UID Fake fork v0.3.6 — краткий статус и справка RU/EN

**Обновление ядрового модуля KernelSU / KernelSU Next** на основе успешно проверенной сборки `0.3.6-test`. Это установочный ZIP **HMA UID Fake**, не APK HMA-OSS LSPosed.

### Что изменилось

- **Чистое описание в KernelSU.** Вместо длинной технической строки модуль показывает только `✅ Работает` / `❌ Не работает` (либо `✅ Working` / `❌ Not working`). Статус обновляется автоматически по наличию ответов от ядра, работающих перехватов и активной политики.
- **Подробная справка по кнопке `?`.** Объяснения для главной страницы, Manage apps, App rule, Templates, Template details, выбора приложений и шаблонов, Settings, Raw config, Backup & restore, About и How it works.
- **Русские и английские пояснения.** Названия функций и пунктов меню оставлены на английском. Содержимое справочных окон, тексты About → How it works и короткий статус зависят от языка Android при установке.
- **Улучшено определение системного языка Android.** Дополнительно используется активная конфигурация `am get-config`, а также системные свойства в качестве резервного источника.
- **Без изменений ядровых хуков и правил.** Механизмы скрытия UID и синхронизации с HMA/HMA-OSS остались такими же, как в предыдущей рабочей версии.

### Установка / Installation

1. Скачайте **`hma-uidfake-fork-latest.zip`** в разделе Assets ниже.
2. KernelSU Next → **Модули** → **Установить из хранилища**. Установите поверх `0.3.5` или ранее установленной тестовой версии.
3. Перезагрузите устройство **один раз**.
4. Откройте WebUI и проверьте справку по `?`, а также описание в KernelSU.

English: Download the ZIP, install via KernelSU Next Modules, and perform one normal reboot. English feature labels remain unchanged; the `?` help dialogs and About text follow the Android system locale captured at installation.

**8 вариантов KMI (ARM64):** `android12-5.10`, `android13-5.10`, `android13-5.15`, `android14-5.15`, `android14-6.1`, `android15-6.6`, `android16-6.12`, `android17-6.18`.

**Важно:** компиляция восьми KMI прошла успешно; загрузка не проверена на каждом устройстве. Перед установкой сохраните возможность восстановления. Модуль не заменяет HMA-OSS и не перехватывает Java PackageManager API.
