# HMA UID Fake fork 0.3.7

Автоматическое определение KMI на кастомных ядрах. Основано на проверенной пользователем сборке `0.3.6-fork+58204e2-TEST-KMI`.

## Изменения относительно 0.3.6

- Добавлено определение совместимого модуля для кастомных ядер без `android13`/`android14` в `uname -r`: используются ELF build ID реально загруженных модулей и контрольные суммы ABI.
- Выбор допускается только при однозначном совпадении: обязательный `module_layout`, не менее восьми общих CRC и отсутствие обнаруженных несовпадений. Версия Linux, модель телефона и версия Android сами по себе не являются основанием для загрузки.
- Восстановлены проверки экспортов и CRC в DDK modpost; все восемь KMI собираются с полноценными таблицами версий символов.
- Модуль загружается штатным `finit_module` без принудительных флагов, изменения vermagic и обхода проверок ядра. Непроверенные импорты окончательно проверяет ядро при загрузке.
- Сохранён автоматический запуск и синхронизация HMA/HMA-OSS. Все варианты KMI сохраняются в пакете, выбор повторяется после перезагрузки. Улучшена диагностика отказов в установщике, статусе и журналах.
- Добавлены тесты выбора KMI, неоднозначных и несовместимых вариантов, загрузчика и реальных ELF-файлов. Версия: `0.3.7-fork`, versionCode: `3007`.

## Установка

Скачайте **hma-uidfake-fork-0.3.7.zip** из Assets, установите поверх предыдущей версии через KernelSU / KernelSU Next и выполните обычную перезагрузку. Конфигурация сохраняется; вручную выбирать `.ko` не нужно. Контрольная сумма находится в `SHA256SUMS`.

Поддерживаемые ARM64 KMI: android12-5.10, android13-5.10, android13-5.15, android14-5.15, android14-6.1, android15-6.6, android16-6.12, android17-6.18.

## Проверка и ограничения

Пользователь подтвердил работу тестовой реализации на кастомном ядре 5.15 устройства Redmi K70 / POCO F6 Pro с LineageOS 23.2: модуль отвечает, правила HMA-OSS активны, отображаются 4 native + 4 compat перехвата. Это не подтверждение всех сценариев скрытия или всех устройств.

При недостаточных данных, конфликтующих CRC или неоднозначности загрузка безопасно отклоняется. Даже определённый KMI не гарантирует совместимость всех хуков с изменениями производителя. Перед установкой сохраните способ восстановления; для запрета загрузки используйте `/data/adb/hma-uidfake/disable_load`.
