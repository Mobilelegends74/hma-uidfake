## HMA UID Fake fork 0.3.16

Изменения относительно 0.3.14:

- Добавлен отдельный вариант ABI `6.12.38` и его автоматическое определение. Стандартный вариант 6.12 и остальные KMI сохранены.
- Устранён обязательный импорт `path_put`, вызывавший отказ загрузки на Pixel с ядром 6.1.162. При недоступности необходимых функций модуль прекращает инициализацию с диагностикой.
- Manual inject: ровная сетка из двух колонок, подписи по версиям, выбор только из вариантов текущей ветки Linux.
- Добавлена поддержка кнопки обновления в совместимых рут-менеджерах. Канал содержит только обычные релизы, без prerelease.

Обычный релиз. Установите ZIP из Assets поверх текущей версии и перезагрузите устройство.
