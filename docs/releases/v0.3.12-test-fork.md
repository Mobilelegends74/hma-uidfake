# HMA UID Fake fork 0.3.12 TEST

Тестовая версия на основе 0.3.11 с переключением HMA/HMA-OSS ↔ Ручной и кнопкой диагностики. Stable / Latest остаётся 0.3.7-fork.

- Добавлен пункт **Manual inject**, видимый только когда sync-tool подтверждает отсутствие ядрового endpoint. Он предлагает восемь KMI из комплекта, пояснение и отдельное подтверждение загрузки.
- Это выбор ядрового `.ko`, не прошивка/замена ядра телефона. Перед загрузкой повторяется проверка совместимости. Неизвестный ABI, неверный KMI, несовпадающие CRC и запрет загрузки владельцем не обходятся. Используется только `finit_module(flags=0)`; нет force-load, переписывания vermagic/CRC и автоматического перебора кандидатов.
- Добавлена взаимная блокировка загрузчика для boot/WebUI и блокировка единственного процесса синхронизации. Уже загруженный модуль не заменяется и не выгружается. После успешного ручного запуска запускается синхронизация выбранного источника правил; автоматический выбор на следующей перезагрузке сохранён.
- Результат и причина отказа показываются в интерфейсе; выбранный вручную KMI и журнал попытки входят в архив диагностики. Настройки правил не меняются.
- Лимит диагностики списка правил Duck Detector увеличен с 25 до 120 секунд: на OnePlus Ace первое сканирование пресетов занимало около 66 секунд.

**Ограничение Kitsune-SpiritFox 5.10.269 #20:** ручной выбор не устраняет подтверждённые 15 несовпадений ABI с текущим android12-5.10 `.ko`. Такой кандидат будет отклонён с `ABI_KERNEL_MISMATCH`. Для загрузки нужна согласованная сборка под точные исходники/config/build tree установленного ядра. Этот prerelease не заявляет исправление совместимости данного ядра или обход всех проверок Duck Detector.

Установите ZIP поверх предыдущей тестовой версии и перезагрузитесь. Если ядровой модуль не загрузился, откройте WebUI → **Manual inject** → выберите KMI → **Проверить и загрузить**. После попытки сохраните диагностику. Успешная сборка и даже принятие `.ko` ядром не доказывают корректную работу всех хуков на устройстве.

Версия `0.3.12-test-fork`, versionCode `3012`. Предыдущие стабильные релизы не заменяются.
