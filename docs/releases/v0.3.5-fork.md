# HMA UID Fake fork v0.3.5 — WebUI RU/EN

### Что нового / What's new

- **Русский и английский интерфейс**: язык определяется по системной локали Android во время установки модуля. Для всех языков, кроме русского, используется английский.
- **Название форка:** `HMA UID Fake fork` в KernelSU и WebUI.
- **Ссылка Source:** теперь ведёт на [Mobilelegends74/hma-uidfake](https://github.com/Mobilelegends74/hma-uidfake).
- Переведены основные экраны, управление приложениями, шаблоны, настройки, справка, диалоги, статусы и уведомления.
- Исправлено отображение длинных подписей на русском языке.
- Сохранены изменения версии 0.3.4: реальные счётчики правил из ядра, 8 KMI, автоматическая загрузка после одной обычной перезагрузки.
- Kernel hooks and HMA / HMA-OSS rule parsing are unchanged from 0.3.4-audit.

### Установка / Installation

Скачайте **`hma-uidfake-fork-latest.zip`** ниже из Assets и установите в KernelSU Next → Модули. Выполните одну обычную перезагрузку. / Download the ZIP from Assets, install it through KernelSU Next Modules, and reboot once.

**Поддерживаемые KMI:** `android12-5.10`, `android13-5.10`, `android13-5.15`, `android14-5.15`, `android14-6.1`, `android15-6.6`, `android16-6.12`, `android17-6.18`.

> **Важно / Important:** каждая KMI-сборка прошла компиляцию в CI, но не проверена на всех физических устройствах. Перед прошивкой подготовьте способ восстановления. / Passing CI does not prove boot compatibility with every vendor kernel. Keep recovery available.
